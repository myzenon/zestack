# Knowledge cleanup

Use this only when the human asks for cleanup, compaction, deduplication, or reorganizing.

Read the project's `index.md` and only the named topic. Keep durable rules, decisions, warnings, paths, and `last-verified` markers. Remove stale implementation history, routine logs, duplicated examples, and replaced wording.

Ask before deleting a rule or changing what an accepted decision means, because those are the human's decisions. Keep `index.md` matching the topics that remain.
